# Based on YOLOv8 deep learning, five weed detection systems (YOLOv8+Y)

## Body

Based on the YOLOv8 deep learning algorithm, this project has developed a smart weed detection system for farmland, specifically targeting five common weed categories ('ji', 'caodizaoshuhe', 'shacao', 'li', 'yumi'). The system uses a large-scale labeled dataset for training, including 4971 images in the training set and 312 images in the validation set. By optimizing the model structure and training strategies, it achieves efficient weed detection in complex farmland environments. The system can process farmland images in real time, accurately identify weed species, and mark their locations, providing an intelligent solution for precision agriculture weeding operations. Experimental results show that the system achieves high detection accuracy and recall rates on the validation set, meeting the application needs of actual farmland scenarios.
